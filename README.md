# Poker Odds Simulator

This program is fully featured Texas Hold'em odds calculator built in Java, designed using the Monte Carlo simulation method and will develop into a complete poker analysis tool. The project begins with basic pre-flop simulations and will grow into a full hand evaluator capable of analysing every stage of the game: pre-flop, flop, turn, and river.

This repository represents an ongoing development from starting simple, improving steadily, and aiming to become an accurate and fully working poker odds engine.

---

## Project Goals

The final version of this program will include:

### 1. Evaluate Real Poker Hand

The program will include a complete hand-ranking system capable of detecting:

- High Card  
- Pair  
- Two Pair  
- Three of a Kind  
- Straight  
- Flush  
- Full House  
- Four of a Kind  
- Straight Flush  
- Royal Flush

### 2. Provide Accurate Odds

The simulator will calculate:

- Pre‑flop odds  
- Flop odds  
- Turn odds  
- River odds

Users will be able to input known cards (e.g., revealed flop cards or known opponent cards when they fold) to refine the simulation.

### 3. Use Monte Carlo Simulation for Realistic Results

The final version will run thousands of random simulations to estimate:

- Win percentage  
- Tie percentage  
- Loss percentage  
- Improvement chances (outs)
